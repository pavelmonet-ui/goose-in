Goose in Shoes — Visual References
This folder contains the visual references for the Goose in Shoes Shopify website.
Files

phrase.JPG — logo / handwritten slogan reference. The phrase “Made for the moments in between.” should preserve this handwritten visual style.
references 2.pdf — website design references, layout inspiration, typography, composition and visual ideas.
Instructions
Use these files as visual guidance when designing the website.
The website should feel:
premium
warm
handmade
tactile
minimal
distinctive
slightly playful
product-focused
Do not directly copy any reference website.
The store will initially contain only four slipper models, so the design should focus on quality rather than quantity.
The primary goal is conversion: a visitor should quickly understand the product, feel that it is a premium handmade designer item, click on a slipper model and purchase it.
